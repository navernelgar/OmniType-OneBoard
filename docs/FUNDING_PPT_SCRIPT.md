## 슬라이드 1: 표지
**원타 키보드**
WONTA Keyboard

---

## 슬라이드 2: 왜 만들었나
> 누군가에겐 키보드가 당연하지 않습니다.

- 시각장애인은 점자 키보드가 별도로 필요합니다
- 다국어 환경의 이민자는 자판을 매번 바꿔야 합니다
- 학생은 수식을 쓰려면 별도 앱을 열어야 합니다
- 이 모든 불편을 하나로 해결하고 싶었습니다

---

## 슬라이드 3: 원타 키보드란?
> 26개 키 하나로, 9개국어 + 수학 + 화학 + 점자를 입력하는 키보드

- 한국어 / English / 日本語 / 中文 / العربية / Русский
- ∑ 수학 97개 부호 (코드 조합)
- ⚗ 화학 142개 원소/반응식
- ⠿ 점자 실시간 변환 (한국/영문)

---

## 슬라이드 4: 핵심 기술
**26키 × 조합 = 무한 부호**

훈민정음과 같은 원리:
- 자음 + 모음 → 한글
- 코드 + 코드 → 수학 부호
- 코드 + 코드 → 화학 원소
- 글자 입력 → 점자 자동 변환

## 슬라이드 6: 점자 — 이 프로젝트의 이유
> 키보드가 불편한 사람들을 위해 만들었습니다.

- 한국 점자 (KS X 6523) 표준 검증 완료
- 영문 점자 Grade 1 표준 검증 완료
- 그냥 타이핑하면 점자로 변환됩니다
- 시각장애인 교육자, 점자 학습자를 위한 도구

---

## 슬라이드 7: 표준 자판
> 각 나라 사람이 익숙한 자판 그대로.

| 언어 | 자판 |
|------|------|
| 한국어 | 2벌식 (표준) |
| English | QWERTY |
| 日本語 | QWERTY 로마자 |
| 中文 | 창힐/병음/명퀘 선택 가능 |
| Русский | ЙЦУКЕН |
| العربية | 아랍 표준 |

---

## 슬라이드 8: 5층 엘리베이터
> 자연어 ↔ 부호 ↔ 도식 ↔ 이진 ↔ 실행

단순 키보드가 아닙니다.
입력한 수식을 계산하고, 화학식의 분자량을 구하고,
코드를 자연어로 역변환합니다.
